# AllPredictor Sports Live — исходники

Это исходный код опубликованной серверной версии:

<https://allpredictor-sports-live.miuipro1993.chatgpt.site/>

## Запуск

```bash
npm install
npm run dev
```

Откройте <http://localhost:3000>.

## Данные

Расписание и доступная форма загружаются из публичного API TheSportsDB.
Используется опубликованный сервисом бесплатный ключ `123`. Приватных ключей
из APK здесь нет.

Прогноз — простая статистическая оценка по доступной форме, а не гарантия.
Сайт не принимает деньги, не выполняет ставки и не хранит данные букмекера.
