# AllPredictor Спорт — русская версия

Одностраничный спортивный анализатор на русском языке, подготовленный после
исследования Android-приложения AllPredictor 4.4.23.

**Запуск:** <https://miuiproking.github.io/-allpredictor-sports-ru/>

## Что работает

- 12 спортивных режимов: футбол, FIFA e-sport, теннис, баскетбол, хоккей,
  волейбол, гандбол, бейсбол, регби, американский футбол, AFL и Формула‑1;
- анализ коэффициентов без букмекерской маржи;
- сравнение формы, атаки, защиты, темпа и непредсказуемости;
- выбор подходящего рынка и объяснение причин;
- оценка риска и индекс согласованности введённых данных;
- локальная история анализов;
- сохранение текстового отчёта;
- полностью автономная работа в браузере без внешних библиотек.

Откройте `index.html` или используйте опубликованную страницу GitHub Pages.

## Важное ограничение

Текущая версия анализирует данные, которые пользователь вводит вручную. Это не
гарантия выигрыша и не точная копия закрытой модели исходного приложения.
Публикация на GitHub сама по себе не добавляет реальные матчи или гарантированную
точность.

Для автоматического режима нужны собственные разрешённые ключи спортивных API и
серверный прокси. Ключи нельзя помещать в HTML: любой посетитель сможет их
скопировать. Найденные в APK адреса и результаты проверки описаны в
[`APK_API_NOTES.md`](APK_API_NOTES.md).

## Запуск локально

Файл не требует сборки:

1. скачайте репозиторий;
2. откройте `index.html` в современном браузере.

## Статус проекта

Это независимая исследовательская реализация. Репозиторий не является официальным
продуктом AllPredictor и не содержит чужих API-ключей, учётных данных или
закрытого серверного кода.
