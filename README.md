# AllPredictor Sports Live — русская версия

**Рабочий сайт:** <https://allpredictor-sports-live.miuipro1993.chatgpt.site/>

**Короткая ссылка GitHub Pages:** <https://miuiproking.github.io/-allpredictor-sports-ru/>

## Что работает

- реальные матчи из публичного API TheSportsDB;
- футбол, теннис, баскетбол, хоккей, бейсбол и регби;
- даты и время по Киеву;
- доступная недавняя форма участников;
- прозрачная статистическая оценка исходов `1 / X / 2`;
- уровень уверенности и объяснение расчёта;
- локальная памятка выбранного исхода;
- пошаговое объяснение работы с букмекерским купоном;
- адаптивный интерфейс для телефона.

GitHub Pages автоматически переводит посетителя на рабочее серверное приложение.
Прежний автономный анализатор сохранён в [`manual.html`](manual.html).

## Как считается оценка

Модель сравнивает доступные победы, ничьи, поражения, среднюю
результативность и баланс забитых/пропущенных. При малой выборке результат
приближается к нейтральной вероятности и получает низкую уверенность.

Составы, травмы, погода и букмекерские коэффициенты не учитываются. Проценты в
интерфейсе — аналитическая оценка, а не коэффициенты и не гарантия выигрыша.

## Безопасность

Сайт не принимает ставки и деньги, не хранит логин, пароль или банковские
данные букмекера. В репозитории нет приватных ключей из APK. Публичный ключ
TheSportsDB `123` опубликован самим сервисом для бесплатного API.

Ссылка букмекера открывается отдельно. Пользователь должен самостоятельно
проверить адрес, лицензию и правовые/возрастные ограничения. 18+; игра на
деньги связана с риском.
