# Безопасность

Не добавляйте API-ключи, пароли, токены Firebase или другие учётные данные в
`index.html`, JavaScript, историю Git и GitHub Actions.

Для интеграции спортивных API используйте отдельный серверный прокси:

1. секрет хранится в переменной окружения сервера;
2. браузер отправляет запрос только вашему прокси;
3. прокси добавляет `X-API-Key` на серверной стороне;
4. ответы ограничиваются нужными полями, источниками и частотой запросов.

Если секрет случайно попал в commit, его необходимо сразу отозвать у поставщика,
создать новый и удалить старый из истории репозитория.
